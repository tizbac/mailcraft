| 2026-11-19 | Gap 15: File › Print (Ctrl+P) prints a message as pages instead of plain text. `crates/print` (`mailcraft-print`) sets them itself from the same display blocks the reading pane draws — the subject, sender, recipients, date and file names, then headings, bold and italic, colours, lists, quotes, rules, tables and pictures — on A4 or Letter, each page numbered at its foot, using the window's own fonts and picking for each word the first face that has its letters. A Print dialog (`ui.printDialog`) chooses the printer, the copies, collating, two sided and black and white; `file.print` runs it with what was chosen. Nothing is fetched for a page: a picture written into the message or attached to it is printed, one on the web only if the owner let pictures come in and the window already has its bytes, and one with no bytes prints what it says it is. Windows prints through the system's print spooler in this process, Linux, macOS and the BSDs through CUPS (`craft-print`): no shell, no viewer, and nothing that runs. The command line and an agent still get the message as printable text. The calendar, the contacts and tasks print nothing yet, and the browser build has no spooler |

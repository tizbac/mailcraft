- **A valid certificate whose authority publishes revocation only as a CRL is no longer read as revoked on Android** (Let's Encrypt, Google Trust Services and others, since OCSP was dropped). Android's own certificate check fetches the CRL over HTTP, which the app's network security configuration had forbidden, so every such certificate failed with “invalid peer certificate: Revoked”. The CRL hosts its verifier names are now allowed over cleartext, and nothing else is.

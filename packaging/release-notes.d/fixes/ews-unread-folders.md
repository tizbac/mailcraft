- **A folder an Exchange server won't read is named, with why.** Where Send/Receive used to say only "Some folders couldn't be read from the server", it now names the folder as you know it and gives the server's response code (`ErrorAccessDenied`, say), or says its answer couldn't be used or was larger than MailCraft reads. The log gets the folder's place in the run and the same safe reason. The other folders are still read, and three folders in a row that can't be read still end the run. No server text and no credential is kept.

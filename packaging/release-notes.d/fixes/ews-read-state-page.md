- An Exchange server account's folder keeps being brought up to date when its page of changes carries more read-state changes than a page takes in: Grommunio and Gromox send the read flags they already sent with every new page, so a folder whose mail had been read in bulk stopped syncing. Such a page is no longer refused — its newest read states are kept, the rest left out, the folder goes on from the state the server gave, and the log says so once. A folder's changes are now asked for 512 at a time, the most the server's schema allows, which is four times fewer requests.

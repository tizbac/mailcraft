- **A copied range of a spreadsheet pastes as a table.** Excel writes the `<table>` its rows sit in outside the clipboard's fragment markers, so the grid used to come through as loose lines; it is taken in with them now. Where the clipboard carries only text — rows of lines with the cells of a row between tabs, as Excel, LibreOffice Calc and Google Sheets write it — an HTML message gets a table, selectable and removable as one block. Plain-text messages and signatures keep it as text.
- **Insert › Table** puts an empty grid at the caret (`insert.table`: `rows` and `columns`, 3 by 3 by default).

- **A message of up to 200 MB comes down whole, on every kind of account.** Exchange server accounts stopped at about 12 MB, JMAP at 50 MB, IMAP at 25 MB; "Download messages in full: Everything" now means up to that ceiling rather than an unbounded read. A message bigger than the account's setting is fetched when it is opened, and one bigger than 200 MB is passed over by a batch of fetches instead of stopping the run, with the reading pane naming both sizes.
- **A run that could not reach its Exchange server says which one, and what the connection said.** "Couldn't reach the server at mail.example.org (the server closed the connection)", "the account's settings name a server that can't be used: mail.example.org (the address is not a web address)". A server that took too long, or answered more than the request may read, or hung up is named by what it did, not as "a connection failure the transport did not classify".

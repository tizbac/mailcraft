- **A failed Exchange message download says what the server's answer lacked, and keeps the answer.** When a download's answer is not the one expected, the error now names it — no `GetItemResponse`, no `Items`, no `MimeContent`, a `MimeContent` that is not base64 — instead of the bare “the server's answer wasn't the answer to the request”, and the whole answer is saved for diagnosis in MailCraft's data folder (Send/Receive problems says where), as an answer that could not be read already was.

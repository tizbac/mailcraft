- **A run that could not reach its Exchange server says which one, and what the connection said.** "Couldn't reach the server at mail.example.org:444 (the server refused the connection)" rather than "Couldn't reach the server": in the status line, in Send/Receive Progress, and in the log line that says a background download of messages stopped and when it tries again, which now carries up to three of the run's lines. So an account whose server is unreachable is not taken for one whose sign-in was refused, and one account is not confused with another. What is named is the host and port the owner gave in Account Settings: no path, no credential, nothing a server answered.

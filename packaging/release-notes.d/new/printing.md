- **Printing a message, as pages.** File › Print (Ctrl+P) prints the selected message on the printer you choose: its subject, sender, recipients, date and file names, then its text with headings, bold and italic, colours, lists, quotes, rules, tables and pictures, on A4 or Letter, every page numbered at its foot. The Print dialog asks for the printer, the copies, collating, two sided and black and white. MailCraft sets the pages itself; the system's own spooler takes them (CUPS on Linux, macOS and the BSDs, the Windows print spooler on Windows), so nothing else is opened and nothing in a message runs. A picture written into the message or attached to it is printed; one on the web is printed only if you had let pictures download and the window already has it, and one with no pictures at all prints the words that say what it is. Hidden sender text is never printed. The calendar, contacts and tasks are not printed yet, and the browser build has no printer to spool to.

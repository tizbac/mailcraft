- **Copying text from a message keeps its formatting.** Ctrl+C (or Copy) in a message being read puts the selected text on the clipboard as HTML beside its plain text, with the look the message gave it — paragraphs, bold, italic, underline, strike-through, colours, sizes, fonts and links — so that it keeps that look pasted into another mail, into Word or Outlook, or into LibreOffice; a word processor that takes HTML is given it, and anything else the text as before. A message's header is copied as text, as it was.

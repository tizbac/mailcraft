- **Outlook `.msg` files can be opened.** A `.msg` file dropped on the window, double-clicked, or brought in with File › Import is read: its subject, sender and their SMTP address beside an Exchange one, To/Cc/Bcc (from the recipient storages, or the display lines when there are none), the text, HTML or rich-text body, the dates, the read and flag state, importance, the message id and header block, and its attachments — a message attached to a message comes in as a `.msg` file of its own, one level deep. Strings written in the older one-byte form are read in the code page the file names (1251, 950, …), so Cyrillic and Chinese subjects are no longer mojibake. A file that isn't a compound file, or holds an appointment, a contact, a task, a note or a post, is refused with that said. Save Message As is unchanged, and reading then writing a `.msg` keeps its note, recipients and attachments; the same property ids are shared by both directions.

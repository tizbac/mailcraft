- A shared mailbox can be opened under an Exchange server account as it can under a Microsoft account: Add Shared Mailbox reads its folders and mail at its own address with the owner's sign-in, a message there can be read in full, and mail written in it is sent from its address when the server allows Send As or Send on Behalf, with the copy filed in its own Sent Items ([#70](https://github.com/GITHUB_REPOSITORY/issues/70)).

- **Exchange accounts on Android.** Add Account offers “Add an Exchange account”: the address, a display name, the user name the server knows (`DOMAIN\user` or a UPN), the password, and the server's Exchange Web Services address (filled in from the domain as `https://…/EWS/Exchange.asmx`). Its mail, calendars, address books and to-dos are kept in step on every Send/Receive and by the background worker, mail written there waits in its Outbox and goes out on the next Send/Receive, and a message is downloaded whole when it is opened. The password is kept in memory for the session and, when sign-ins are remembered, in the phone's secure store; it is removed with the account. A server whose certificate the phone doesn't trust yet stops with a line in Send/Receive's problems (there is no prompt to pin its fingerprint on the phone yet).

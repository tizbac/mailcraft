- **Calendars on a personal calendar server are kept both ways.** With a CalDAV server set up in File › Info › Calendars and Contacts (or found for a Linchange account at sign-in), appointments made, changed and deleted here go up at the next Send/Receive, and the server's come down. A change made on a version the server has changed since is never put over it: the window asks which copy to keep, or — with "When the server's copy changed too, keep both" on — the server's is read and what was changed here is kept as a copy of its own. Conditional writes (`If-Match`, `If-None-Match: *`) throughout.
- **A Linchange account gets its calendars and address books at sign-in**, on the desktop and on Android: the server's own names are found from its mail host, and the phone's Calendar and Contacts apps mirror them.

- **An Arch Linux package**: `packaging/arch` has a source `PKGBUILD` (with the desktop entry, MIME types, AppStream metadata and icons the other Linux packages carry) and `package.sh`, which stages the checkout as a tarball and builds `dist/release/mailcraft-<version>-1-<arch>.pkg.tar.zst` with `makepkg`; `--install` runs `pacman -U`. It is built from the checkout rather than by the release workflow, so it follows a tag or any commit.
